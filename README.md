# חבילת שפה עברית ל-VS Code

חבילת השפה העברית מספקת ממשק משתמש מתורגם עבור Visual Studio Code.

הגרסה הנוכחית תואמת ל-**VS Code 1.137** וכוללת **24,243 מחרוזות ליבה** ב-1,962 מודולים,
ועוד **4,056 מחרוזות** ב-93 ההרחבות המובנות.

## התקנה ושימוש

ניתן לעקוף את שפת ברירת המחדל של הממשק על ידי הגדרת שפת התצוגה של VS Code
באמצעות הפקודה **Configure Display Language**.

לחץ על `Ctrl+Shift+P` כדי לפתוח את **Command Palette**, והתחל להקליד `display`
כדי לסנן ולהציג את הפקודה **Configure Display Language**.

לחץ על `Enter` ותוצג רשימת שפות מותקנות לפי אזור, כאשר האזור הנוכחי מסומן.
בחר `עברית` כדי להחליף את שפת הממשק, ואז טען מחדש את החלון.

## מוסכמות התרגום

התרגום מיישר קו עם קונבנציות העברית של קטלוגי GitLens. ההחלטה המנחה היא **רגיסטר היברידי**:

- **פעולות Git** שומרות על שמן המוכר בתעתיק עברי — קומיט, ריבייס, סטאש, צ'רי-פיק, סקווש, צ'ק-אאוט.
- **שמות עצם של אובייקטי Git ומונחי ממשק** הם עברית אמיתית — ענף, תג, מאגר, עץ עבודה,
  סרגל צד, חלונית, שורת המצב, בורר מהיר.
- **אין ערבוב אותיות לטיניות בתוך פרוזה עברית**, למעט שמות מוצר, תחביר Git, מזהים ונתיבים —
  זה מה שמונע שבירה של הרינדור הדו-כיווני.
- **מותג לטיני אינו פותח כותרת עברית**: `מצב Git`, ולא `Git מצב`.
- **פקודות, תפריטים וכפתורים** בציווי זכר יחיד (`פתח`, `הצג`, `מחק`);
  **תיאורי הגדרות** בגוף שלישי הווה (`מציין…`, `קובע…`).
- **אין תווי בקרה דו-כיווניים** (U+200E/U+200F/U+202A–U+202E) בערכים — הפריסה היא באחריות הרנדרר.
- אין צורות כפולות-מגדר כמו "לחץ/י".

## בנייה מהמקור

```bash
git clone https://github.com/AMAARETS/vscode-language-pack-he
cd vscode-language-pack-he
npx @vscode/vsce package
```
